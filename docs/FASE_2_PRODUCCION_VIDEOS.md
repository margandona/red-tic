# Fase 2 - Producción de Videos: Estrategias por Clase

Programa: Ayudantía TIC: Competencias Digitales para la Vida Académica
Duración deseada por video: 3-6 minutos
Formato de entrega: URL embedible (YouTube no listado o institucional)

---

## Clase 1 - Acceso al Sistema Académico

**Recomendación:** Clipchamp (screen recording) + voz en off

### Opción A: Clipchamp (Screen Recording + Voz)
Ideal para demostrar navegación real en aula virtual.

**Contenido a grabar:**
1. Pantalla de inicio navegador.
2. Ir a plataforma institucional.
3. Ingreso con credenciales.
4. Panel principal: ubicar avisos, tareas, calendario.
5. Menú lateral: navegación por secciones.
6. Consejos de seguridad y favoritos.

**Guion sugerido (voz en off):**
```
"Hola, bienvenido a tu primer paso en el aula virtual.
Para acceder, abre tu navegador favorito: Chrome, Edge o Firefox.
Dirígete a [plataforma.com]. Aquí ves el inicio de sesión.
Ingresa tu usuario y contraseña institucionales. 
[Pausa mostrando pantalla]
Listo, estás dentro. En esta pantalla principal ves:
- Mis cursos (donde están todas tus asignaturas)
- Avisos importantes
- Tu calendario académico
En el lateral izquierdo están todas las secciones:
- Calificaciones
- Tareas
- Contenido de clase
Un consejo importante: guarda este enlace en favoritos
para no caer en sitios falsos.
¡Ahora tú: intenta ingresar y explorar estas 3 secciones!"
```

**Pasos en Clipchamp:**
1. Ve a clipchamp.com (requiere cuenta Microsoft/gratuita).
2. Nuevo proyecto > Screen recording + web camera.
3. Captura pantalla + micrófono (asegura audio claro).
4. Graba mientras navegas (3-5 min).
5. Pausa en secciones clave para que vea bien.
6. Edita: recorta, ajusta velocidad, agrega títulos.
7. Exporta como video en resolución 720p.
8. Carga en YouTube (no listado) u otra plataforma.

**Diapositivas sugeridas (total 10-12):**
1. Portada: "Comunicación Académica Efectiva"
2. "¿Por qué importa la comunicación académica?" (puntos clave)
3. "Partes básicas de un correo" (Para, Asunto, Cuerpo, Firma)

### Opción B: Clipchamp (Screen Recording)
Grabar cliente de correo real en vivo.

**Contenido a grabar:**
1. Gmail o Outlook abierto.
2. Nuevo correo.
3. Mostrar campo "Para", "Asunto", cuerpo.
4. Escribir un ejemplo de correo paso a paso.
5. Mostrar cómo adjuntar archivo.
6. Enviar.

**Guion:**
```
"Hoy aprenderemos a escribir correos académicos.
Un buen correo abre puertas; uno mal escrito cierra oportunidades.
[Abre Gmail] Aquí ves el botón 'Redactar'. Haz clic.
Se abre el formulario. Llenamos paso a paso:
1. Para: El correo del profesor (sin errores)
2. Asunto: Breve y específico. NO escribas 'Hola' o 'Consulta general'
Aquí escribo: 'Solicitud de prórroga - Tarea Clase 5'
3. El cuerpo. Empieza con un saludo formal...
[Escribe ejemplo]
4. Firma con tu nombre completo y cédula.
5. Adjunto si es necesario. Presiona 'Adjuntar archivo'
6. Revisa antes de enviar. ¿Dirección correcta? ¿Asunto claro? ¿Sin faltas?
7. Envía. ¡Listo!"
```

## Clase 3 - Producción Académica: Office 365

**Recomendación:** Clipchamp (screen recording de Office)

### Opción A: Clipchamp (Screen Recording - Mejor para esta clase)
Screen recording mostrando Word, PowerPoint y Excel en acción.

**Contenido a grabar (3 segmentos de 2 min cada uno):**

#### Segmento 1: Word (Documento)
```
"Hola, vamos a crear un documento profesional en Word.
[Abre Word con plantilla APA]
Lo primero: elige una plantilla que tenga estructura clara.
Aquí ves los estilos: Título, Subtítulo, Cuerpo de texto.
[Escribe un título de ejemplo]
USO de estilos es clave. Mira, cuando aplico 'Título 1',
el documento genera automáticamente tabla de contenidos.
[Muestra tabla de contenidos automática]
Ahora formato: márgenes, interlineado, alineación.
[Ajusta formato]
Agrega imágenes: Insertar > Imágenes. [Inserta una]
Y referencias: Citas y bibliografía. [Muestra)
¡Listo! Documento listo para entregar. 
Antes de enviar: exporta a PDF para que no se dañe el formato.
Archivo > Exportar como PDF."
```

#### Segmento 2: PowerPoint (Presentación)
```
"Ahora PowerPoint. Una presentación fuerte = menos texto, más imágenes.
[Abre PowerPoint con diseño limpio]
Regla de oro: máximo 5 líneas por diapositiva.
[Muestra una diapositiva bien diseñada]
Elige un tema consistente desde el inicio.
[Cambia tema]
Las imágenes deben estar alineadas y ser de buena calidad.
[Inserta imágenes bien]
Número de diapositivas: 10 es un mínimo para un tema sustancial.
[Muestra vista de navegación]
Ahora practica: 'Transiciones'. Las transiciones dan fluidez
pero úsalas con moderación. Una o dos por toda la presentación.
[Agrega una transición]
¡Listo! Tu presentación está lista para exponer."
```

#### Segmento 3: Excel (Hoja de Cálculo)
```
"Finalmente, Excel. Para datos y gráficos.
[Abre Excel]
Aquí vamos a registrar calificaciones y hacer un análisis.
[Ingresa datos de ejemplo]
Fórmula importante: PROMEDIO. [Escribe =PROMEDIO(...)]
También SUMA, CONTEO según necesites.
[Muestra varias fórmulas]
Ahora un gráfico: selecciona los datos > Insertar > Gráfico.
[Crea gráfico]
Los gráficos comunican información rápido.
Elige el tipo según tu dato: barras para comparación,
línea para tendencia, pastel para proporciones.
Y listo, tu análisis está visual y profesional."
```

**Pasos Clipchamp:**
1. Abre Clipchamp.
2. Screen recording + micrófono.
3. Graba Office en uso (o cada segmento por separado).
4. Edita: añade títulos, ajusta velocidad, recorta.
5. Exporta 720p.
6. Carga en YouTube (no listado).

## Clase 4 - Mejora tu Aprendizaje con IA

**Recomendación:** Combinado - PowerPoint + Clipchamp demostración en vivo

### Opción A: Clipchamp - Screen Recording (Copilot/ChatGPT)
Grabar VS Code con Copilot activo, o ChatGPT en navegador.

**Contenido a grabar:**
1. Abre VS Code con Copilot.
2. Escribe un comentario: "crea una función que sume dos números"
3. Copilot sugiere código.
4. Explica: "Aquí vemos cómo Copilot entiende mi intención"
5. Acepta la sugerencia y muestra el código.
6. Ahora en ChatGPT: "Explícame la diferencia entre let, var y const en JavaScript"
7. Muestra respuesta y comenta: "La IA explica conceptos de forma clara"
8. Cierre: "Pero SIEMPRE valida. No copies sin revisar"

**Guion:**
```
"Hola, en esta clase aprendemos a trabajar CON IA, no que la IA trabaje POR NOSOTROS.
[Abre VS Code]
Aquí tengo el editor VS Code con la extensión GitHub Copilot.
Escribo un comentario en español describiendo qué quiero:
// Crea una función que súme dos números
[Escribe]
Copilot me da una sugerencia. [Muestra sugerencia]
La miro. ¿Está correcta? ¿Está incompleta? ¿Hay un mejor forma?
En este caso está bien. Acepto.
[Acepta]
Ahora voy a ChatGPT. [Abre ChatGPT]
Le pregunto: ¿Cuál es la diferencia entre let, var y const?
[Espera respuesta]
Aquí IA me explica. Claro, detallado.
Pero yo debo ENTENDER eso. No copié sin leer.
Valido. Busco en documentación oficial si me queda duda.
La IA es una HERRAMIENTA. Úsala para:
- Acelerar tareas repetitivas
- Explicar conceptos
- Revisar tu trabajo
NO la uses para:
- Entregar sin validar
- Evitar aprender
- Copiar sin entender
Ahora tú: prueba Copilot o ChatGPT en algo que estés trabajando.
Valida todo. Aprende. ¡Eso es usar IA responsablemente!"
```

## ❓ Preguntas Sugeridas (6 preguntas)

### Pregunta 1
**Tipo**: Multiple choice
- **Pregunta**: ¿Cómo debe comenzar una fórmula en Excel?
- **Respuesta correcta**: Con el signo igual `=`
- **Opciones incorrectas**:
  - Con el signo `+`
  - Con un punto `.`
  - Con la palabra FORMULA

### Pregunta 2
**Tipo**: Multiple choice
- **Pregunta**: ¿Qué hace la fórmula `=SUMA(B2:B6)`?
- **Respuesta correcta**: Suma todos los valores entre B2 y B6
- **Opciones incorrectas**:
  - Cuenta cuántas celdas hay
  - Ordena los números
  - Busca el valor mayor

### Pregunta 3
**Tipo**: Multiple choice
- **Pregunta**: ¿Qué función usarías para calcular el promedio de notas?
- **Respuesta correcta**: `=PROMEDIO(rango)`
- **Opciones incorrectas**:
  - `=CONTAR(rango)`
  - `=MAX(rango)`
  - `=SUMA(rango)`

### Pregunta 4
**Tipo**: Multiple choice
- **Pregunta**: Si quiero ver solo los estudiantes aprobados, ¿qué herramienta uso?
- **Respuesta correcta**: Filtro
- **Opciones incorrectas**:
  - Bordes de celda
  - Combinar celdas
  - Formato de número

### Pregunta 5
**Tipo**: Multiple choice
- **Pregunta**: Si una celda muestra `####`, normalmente significa que...
- **Respuesta correcta**: La columna es demasiado angosta para mostrar el valor
- **Opciones incorrectas**:
  - La fórmula tiene un error
  - El archivo tiene virus
  - La celda está vacía

### Pregunta 6
**Tipo**: Multiple choice
- **Pregunta**: Antes de crear un gráfico, lo primero es...
- **Respuesta correcta**: Seleccionar correctamente los datos que se van a representar
- **Opciones incorrectas**:
  - Cambiar el nombre del archivo
  - Insertar una imagen
  - Activar modo oscuro

# Actividad Kahoot - Clase 4: Prompt Profesional Universal

## 📊 Información General
- **Nombre del quiz**: Prompting Esencial
- **Clase**: Clase 4
- **Tipo**: Kahoot interactive quiz
- **Duración recomendada**: 4-5 minutos
- **Preguntas**: 4 preguntas
- **Dificultad**: Básico-Intermedio

## 🎯 Objetivos de Aprendizaje
- Identificar la estructura mínima de un buen prompt.
- Reforzar claridad, contexto, formato y restricciones.
- Preparar al estudiante para completar el formulario generador de prompt.

## ❓ Preguntas Sugeridas

### Pregunta 1
**Tipo**: Multiple choice
- **Pregunta**: ¿Qué elemento no puede faltar en un prompt profesional?
- **Respuesta correcta**: La tarea específica que se quiere resolver
- **Opciones incorrectas**:
  - Emojis decorativos
  - Un saludo largo
  - La hora del día

### Pregunta 2
**Tipo**: Multiple choice
- **Pregunta**: ¿Para qué sirve agregar contexto en un prompt?
- **Respuesta correcta**: Para que el LLM entienda mejor la situación y responda con más precisión
- **Opciones incorrectas**:
  - Para hacer el texto más largo sin utilidad
  - Para evitar escribir la tarea principal
  - Para reemplazar el formato de salida

### Pregunta 3
**Tipo**: Multiple choice
- **Pregunta**: Si quieres una respuesta en tabla o pasos, ¿qué debes indicar?
- **Respuesta correcta**: El formato de salida esperado
- **Opciones incorrectas**:
  - Solo el tema general
  - Una despedida cordial
  - El nombre del navegador

### Pregunta 4
**Tipo**: Multiple choice
- **Pregunta**: ¿Qué logran las restricciones en un prompt?
- **Respuesta correcta**: Delimitar tono, extensión, límites y criterios de calidad
- **Opciones incorrectas**:
  - Hacer que la IA responda más lento
  - Impedir cualquier respuesta útil
  - Reemplazar el objetivo del prompt

## 📝 Instrucciones para Crear en Kahoot

1. Crear un quiz llamado **Prompting Esencial**.
2. Ingresar las 4 preguntas anteriores.
3. Usarlo como activación antes del formulario de construcción de prompt.
4. Cerrar con una demostración breve de un prompt bien armado.

## 🎮 Opciones de Kahoot
- Tiempo por pregunta: 30 segundos.
- Ranking en tiempo real: Sí.
- Mostrar respuesta correcta: Sí.
- Modo individual o por parejas: Sí.

## ✅ Criterios de Éxito
- 4 correctas = Comprende la estructura del prompt.
- 3 correctas = Buen punto de partida.
- 2 o menos = Reforzar antes de completar el formulario.

## 📌 Nota
Este Kahoot debe usarse antes del formulario para que el estudiante complete mejores respuestas y genere un prompt más sólido.
